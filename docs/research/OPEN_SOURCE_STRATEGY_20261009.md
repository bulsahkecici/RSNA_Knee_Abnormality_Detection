# External open-source strategy — 2026-10-09

Research only: primary author/institution repositories, papers, model cards and dataset documentation. No large model/data downloads, raw reports, remote runs, or new score claims. The current comparison anchor is our own verified public score 0.767, with six-center DINOv2-S CLS features and a masked study-level mean. External published metrics concern different datasets and cannot be compared directly with that competition score.

## Proposed controlled program

1. Preserve the0.767 artifact, preprocessing identity and receipt. Build an immutable candidate registry: source URL/version/hash, encoder/spec, source terms, dataset provenance, dimensions, observed memory and timings, unknown overlap flag.
2. Run frozen-feature probes for the two most aligned obtainable2D encoders: OrthoFoundation and RadImageNet. Use the same numeric labels and train/validation UIDs; retain uncertain/unmentioned masks. Do not select by cross-task paper AUC.
3. Train class-specific MIL on our DINO features as the low-cost structural control; separately compare CLS with patch-summary features. Add structural sequences/canonical crops as a different experiment with versioned preprocessing.
4. Fine-tune only candidates with useful own validation performance or complementary errors. Start with one fold, then reproduce promising choices with fold-specific initialization on another fold before expensive five-fold training.
5. Compare fixed equal-weight or rank blends of genuinely different readers. Select with masked held-out predictions, uncertainty and per-target regressions; avoid fitting12 separate blend weights on29 gold exams. Distil a validated large teacher ensemble into a compact reader only using training UIDs. For evaluated students, use nested cross-fitting: teachers producing student-training pseudo-labels must also exclude the student's entire outer validation fold from teacher training. Ordinary global OOF pseudo-labels are insufficient, because their producing teachers may have trained on the student's outer validation images. Keep gold-eval images out of all teacher training too.
6. For every selected artifact, run offline end-to-end runtime/schema testing before a scored submission. Limit final ensemble size using observed marginal gain per measured runtime, not the number of available models.

Important validation boundary: the existing frozen-v3 supervised head was trained on folds1–4. Reusing that checkpoint as the initialization of a fold1–4 OOF run leaks those newly held-out studies. Honest fold expansion requires independently trained supervised stages from official unsupervised initialization, excluding all gold-eval images and duplicate groups throughout.

## Compute planning — estimates, not measurements

Frozen features can be extracted once per encoder/cache policy and reused for cheap heads; this is the most practical way to screen many models. OrthoFoundation-L is roughly a large ViT class, materially more costly than DINOv2-S; BiomedCLIP-B is also larger. RadImageNet ResNet50 uses convolutional feature extraction and should be profiled, not assigned a speculative speed advantage. Three3D diffusion backbones require substantially different volume/memory handling; their1.66 GB listing is weight storage, not GPU memory.

The root controller reports a verified Colab handshake for A100-SXM4-80GB. Use that observed training capability for bounded pilots and frozen-feature extraction; this hardware observation does not establish candidate throughput, training duration, or the accelerator assigned to offline Kaggle scoring. Profile there before defining numerical budgets, and validate final inference on Kaggle's actual assigned device separately.

Doubling centers from6 to12 doubles encoder views and uncompressed image payload before compression; increasing224-pixel images to384 increases pixels about2.94 times, with transformer attention scaling further with token count. These are arithmetic workload estimates, not GPU-hour promises. Measure representative median and high-slice-count studies, codec failures, loading and full CSV creation. Cap experiments by observed GPU quota and final prediction by the official nine-hour requirement with a safety margin. No hardware or remote service has been acquired by this research.
